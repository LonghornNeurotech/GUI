# Plan 01.5-03: Remove Plot Throttle for Every-Frame Updates

## Goal

Make FFT and band power plots update every frame for smooth real-time display (UX-02) by removing throttle counters in both streaming and file modes.

## Tasks

<task id="01.5-03-T1" title="Remove streaming-mode FFT/band power throttle">
<read_first>
- GUI.py (lines 3611-3619 -- streaming throttle with fft_update_counter)
- GUI.py (lines 678-679 -- fft_update_counter and fft_update_interval init)
</read_first>
<action>
In the `update_stream()` method, find the throttle block (around lines 3614-3619):

```python
# Throttle FFT and band power updates (expensive, ~20Hz is enough)
self.fft_update_counter += 1
if self.fft_update_counter >= self.fft_update_interval:
    self.fft_update_counter = 0
    self.update_fft()
    self.update_band_power()
```

Replace with unconditional calls:

```python
# Update FFT and band power every frame for smooth display
self.update_fft()
self.update_band_power()
```

Keep the `self.fft_update_counter` and `self.fft_update_interval` attribute initializations (lines 678-679) because they are used by the file-mode throttle (line 2772). Only remove the streaming-mode throttle.
</action>
