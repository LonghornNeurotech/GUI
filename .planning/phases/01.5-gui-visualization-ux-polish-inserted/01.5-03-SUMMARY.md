# Phase 01.5 Plan 03: Remove Plot Throttle for Every-Frame Updates Summary

**Removed FFT and band power throttle counters from both streaming and file-playback paths so plots update every frame, eliminating visible lag during live EEG visualization**

## Accomplishments

- Streaming mode: replaced `fft_update_counter` throttle block with unconditional `self.update_fft()` and `self.update_band_power()` calls
- File-playback mode: replaced `fft_update_counter >= 5` throttle block with unconditional `self.calculate_fft_for_file()` and `self.calculate_band_power_for_file()` calls

## Decisions Made

- Removed throttles entirely rather than lowering the interval threshold -- at 60 Hz the FFT and band-power computation is lightweight enough on modern hardware, and any timer-rate limiting is already handled by the Qt timer interval
- Deleted the now-unused `fft_update_counter` and `fft_update_interval` attributes to avoid dead code confusion
